# ETUDE — brag plan

**What it is:** The website for ETUDE, a ballroom & Latin dance school in Rishon LeZion — plus the studio's TV screen and every trainer's calendar, all driven by one shared Google Sheet.
**For:** students (trilingual public site) and staff (no-code schedule: edit a cell, everything follows).
**Sets it apart:** the timetable lives in a spreadsheet; the build turns it into a live studio TV display, per-trainer schedule pages with self-updating calendar feeds, and a HE/EN/RU site — hosted free on GitHub Pages.
**Visual hook:** a spreadsheet cell being typed, then the studio TV showing that class as "NOW".
**Tone:** default — punchy, clean, a little elegant. Music is a waltz (it's a ballroom school).
**Identity:** navy #17224a / brand blue #2f4b9b / ground #f7f8fb; Another Shabby brush lettering for captions, Montserrat for UI.
**Share caption:** "A dance school that runs on one spreadsheet."
